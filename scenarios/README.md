# 장애 주입 시나리오

교육생에게 **고장난 상태**를 주고 원인을 찾게 한다. 성공 경로만 따라가면 트러블슈팅을 못 배운다.

```bash
make break LAB=1 SCENARIO=m01-01      # 주입
make fix   LAB=1 SCENARIO=m01-01      # 복구
make scenarios                        # 목록
```

**규칙**: 교육생은 **복구하기 전에 원인을 말한다.** 근거(명령어 출력·캡처)를 함께 제시해야 한다.
고치는 것보다 **왜 그런지 아는 것**이 목적이다.

| ID | 모듈 | 증상 | 노리는 것 |
|---|---|---|---|
| `m01-01` | M1 | ping 무응답 | L1 부터 보는 습관 (B1) |
| `m01-02` | M1 | 링크는 양쪽 UP 인데 ping 무응답 | 스위치의 역할 이해 (B2) |
| `m01-03` | M1 | 모든 게 정상인데 ping 무응답 | `ip neigh` 를 맹신하지 않기 (B4) |
| `m02-01` | M2 | pc1 만 아무 데도 못 간다 (`Network is unreachable`) | 에러 메시지를 읽는 습관 · 기본 경로 (C1) |
| `m02-02` | M2 | pc2 만 게이트웨이에 못 닿는다. pc1 은 정상 | VLAN 이 트렁크를 지나는지 따라가기 (B3, B5) |
| `m02-03` | M2 | pc2 가 아무 데도 못 간다. pc2 설정은 완벽하다 | 내 설정이 맞으면 반대편 끝을 본다 (B5) |
| `m02-04` | M2 | pc1 만 게이트웨이에 못 닿는다. 트렁크에 VLAN 은 다 있다 | native VLAN 불일치 — 캡처로만 보인다 (B5) ★ |
| `m03-01` | M3 | pc1 → web 무응답. r1·r4 경로는 정상 | 가운데 라우터의 리턴 경로 (D3) |
| `m03-02` | M3 | 경로가 분명히 있는데 통신이 안 된다 | `>*` 를 읽을 줄 아는가 (D2) |
| `m03-03` | M3 | traceroute 에 같은 주소가 반복된다 | 라우팅 루프와 TTL (D2, H5) |
| `m03-04` | M3 | 라우터는 전부 정상인데 안 된다 | 리턴 경로는 서버에도 있다 (D3) |
| `m04-01` | M4 | **증상 없음.** 이중화 점검 지시만 있다 | Area 불일치 — 백업이 조용히 죽어 있다 (D5) ★ |
| `m04-02` | M4 | 통신은 되는데 경로가 백업으로 돈다 | `ExStart` → MTU (D5, C5) ★ |
| `m04-03` | M4 | r4 의 인접 하나가 사라졌다 | 인증 불일치 — 체크리스트 ④ (D5) |
| `m04-04` | M4 | 백업 인접이 안 선다. Area·주소·MTU 는 정상 | 타이머 불일치 — m04-01 과 증상이 같다 (D5) |
| `m06-01` | M6 | IPv4 는 되는데 **IPv6 만** 안 된다 | dual-stack 은 테이블이 두 벌 (C4) |
| `m06-02` | M6 | IPv6 게이트웨이까지는 가는데 서버망만 못 간다 | OSPFv3 광고 누락 (C4) |
| `m06-03` | M6 | IPv6 주소가 설정에는 있는데 동작하지 않는다 | **DAD 실패** — IPv4 에 없던 장애 (C4) ★ |
| `m07-01` | M7 | ping 은 되는데 HTTP 만 매달린다 | 감별표 ② DROP (E3) |
| `m07-02` | M7 | HTTP 가 **즉시 거부**된다 | 감별표 ③ — 즉시 거부 = 네트워크는 정상 (E3) |
| `m07-03` | M7 | 연결은 되는데 응답이 없다 | 감별표 ④ — 프로세스는 살아 있다 (E3) ★ |
| `m07-04` | M7 | `Cannot assign requested address` | 상대가 아니라 **내 쪽** 자원 고갈 (E4) |
| `m08-01` | M8 | 통신은 되는데 **가끔 느리다** | 재전송을 캡처에서 찾기 (H1) |
| `m08-02` | M8 | pc1 에서만 HTTP 가 안 된다 | **어느 구간에서 사라지는가** — 다중 지점 캡처 (H3) ★ |
| `m09-01` | M9 | 이름은 풀리는데 접속이 안 된다 | 응답이 온 것 ≠ **맞는 답**이 온 것 (F1) ★ |
| `m09-02` | M9 | 이름으로는 안 되고 IP 로는 된다 | 판별표 첫 줄 — DNS 서버 장애 (F1) |
| `m09-03` | M9 | 이름 해석이 **느리게** 실패한다 | `dig @서버` 와 `dig` 의 차이 (F1) |
| `m09-04` | M9 | FTP 접속은 되는데 전송만 안 된다 | FTP 는 연결이 **두 개** (F4) |
| `m10-01` | M10 | 내부에서 밖으로 아무것도 안 된다 | SNAT 누락 — 경계 양쪽 캡처 (G1) |
| `m10-02` | M10 | 공개 서비스 하나만 안 된다 | 되는 쪽과의 **차이**를 찾기 (G1) |
| `m10-03` | M10 | 나가는데 **응답이 안 돌아온다** | stateful 허용 규칙 한 줄 (G2) ★ |
| `m10-04` | M10 | 외부 FTP 전송만 안 된다. 내부는 정상 | `227` 에 사설 IP — NAT 는 본문을 못 바꾼다 (F5) ★ |
