API 토큰 만들기 Proxmox 셸에서 한 번

pveum user add terraform@pve
pveum role add Terraform -privs "Datastore.Allocate Datastore.AllocateSpace \
  Datastore.Audit Sys.Audit Sys.Console Sys.Modify VM.Allocate VM.Audit VM.Clone \
  VM.Config.CDROM VM.Config.Cloudinit VM.Config.CPU VM.Config.Disk VM.Config.HWType \
  VM.Config.Memory VM.Config.Network VM.Config.Options VM.Migrate VM.Monitor \
  VM.PowerMgmt User.Modify Pool.Allocate"
pveum aclmod / -user terraform@pve -role Terraform
pveum user token add terraform@pve lab --privsep 0

마지막 명령이 출력하는 value 가 토큰 비밀값이다. 그때 한 번만 보인다.
Sys.Modify 는 랩 브리지를 만들 때 필요하다 — 빼면 VM 은 만들어져도 배선이 안 된다.
--privsep 0 은 토큰이 사용자 권한을 그대로 물려받게 한다. 켜면 토큰에도 따로 권한을 줘야 한다.

이 값이 어디에 쓰이는가

TerraformVM·브리지 생성/삭제 — 주소·노드·데이터스토어·토큰 전부
Ansible랩 노드 설정 — 관리망 경유. Proxmox 자체에는 붙지 않는다
문서·토폴로지교재의 콘솔 접속 주소

저장하면 var/runtime.yml 로 내보내져 CLI 도구도 같은 값을 본다. 토큰 비밀값만은 파일에 쓰지 않고 var/console.db(0600) 에 두었다가 작업 실행 시 환경변수로 넘긴다. 템플릿 VM 은 VMID {{ template_vmid }} 를 쓴다.
