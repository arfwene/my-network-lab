{# 화이트모드 / 다크모드 전환. **기본은 화이트**이고, 고른 값은 그 브라우저에 계속 남는다 — 다음에 다시 들어와도 고른 모드로 열린다. 저장은 localStorage 로 한다. 서버에 두지 않는 이유는, 화면 색이 계정 설정이 아니라 그 자리에서 보는 사람의 취향이기 때문이다 — 강의실 공용 PC 에서 한 번 바꾼 것이 집에서 열 때 따라오면 오히려 성가시다. 글자는 **두 개를 다 심어 두고 CSS 가 고른다.** JS 로 채우면 스크립트가 돌기 전까지 빈 단추가 보이고, 폭이 한 번 튄다. 지금 화면이 어떤 모드인지는 이미 CSS 가 알고 있으니 JS 에게 다시 물을 이유가 없다. 반달 표시도 각 글자 안에 하나씩 넣는다. 밖에 하나만 두면 그것 때문에 테마 선택자를 세 벌 더 써야 한다 — 보이는 쪽이 곧 지금 모드다. #}
