1. 키 만들기

Windows — 시작 메뉴에서 PowerShell 을 검색해 연다. 설치할 것은 없다(Windows 10 이상에 SSH 가 기본 포함).

ssh-keygen -t ed25519 -C "{{ user.username }}@내PC"

세 번 묻는다. 전부 그냥 Enter (저장 위치 기본값, 암호 없음). 그다음 아래로 공개키를 꺼낸다.

Get-Content $HOME\.ssh\id_ed25519.pub

ssh-ed25519 AAAA... 로 시작하는 한 줄이 나온다. 그 줄을 통째로 복사해 아래에 붙여넣는다.

같은 폴더에 이름이 비슷한 파일이 둘 있다.
id_ed25519.pub = 공개키 — 남에게 줘도 되는 자물쇠
id_ed25519 (.pub 없음) = 개인키 — 누구에게도 주지 않는 열쇠
둘을 바꿔 내는 것이 가장 흔한 사고다. 개인키를 붙여넣으면 이 화면이 거절한다.

macOS · Linux 를 쓴다면 
ssh-keygen -t ed25519 -C "{{ user.username }}@내PC"
cat ~/.ssh/id_ed25519.pub

ssh 명령이 없다고 나오면 — Windows 설정 → 시스템 → 선택적 기능 → 기능 추가 → OpenSSH 클라이언트.

랩 노드는 사무실에서 직접 보이지 않는다. 운영 서버를 거쳐야 한다. 매번 이렇게 칠 수는 없다:

ssh -J {{ jump_user }}@{{ jump_ip }} {{ lab_user }}@{{ example_ip }}   # {{ example_node }}

아래에서 내 설정을 받아 ~/.ssh/config 에 붙이면 ssh {{ example_node }} 한 줄로 끝난다.

내 SSH 설정 내려받기 ssh-config-lab{{ lab_id }}

Windows — 받은 파일은 보통 다운로드 폴더에 있다.

New-Item -ItemType Directory -Force $HOME\.ssh | Out-Null
Get-Content $HOME\Downloads\ssh-config-lab{{ lab_id }} | Add-Content $HOME\.ssh\config
ssh {{ example_node }}
macOS · Linux 를 쓴다면 
mkdir -p ~/.ssh
cat ~/Downloads/ssh-config-lab{{ lab_id }} >> ~/.ssh/config
chmod 600 ~/.ssh/config
ssh {{ example_node }}

이 설정은 배정된 랩({{ lab_label }}) 기준이다. 랩이 바뀌면 다시 받아야 한다.

5. 콘솔 — SSH 가 죽었을 때

자기가 관리 링크를 내리면 SSH 자체가 끊긴다. 그때 되돌릴 유일한 길이 화면에 직접 붙는 콘솔이다. 실무의 콘솔 케이블·터미널 서버와 같은 자리다.

콘솔은 키를 쓸 수 없다. 그래서 여기만 비밀번호로 들어간다.

비밀번호를 두 번 넣는다. 하나는 Proxmox 웹에 들어가는 것, 하나는 그 안에서 열린 노드 화면에 로그인하는 것이다. 서로 다른 값이다.
