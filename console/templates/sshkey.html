1. 키 만들기

내 PC 에서 (이미 있으면 건너뛴다):

ssh-keygen -t ed25519 -C "{{ user.username }}@내PC"
cat ~/.ssh/id_ed25519.pub

붙여넣을 것은 .pub 로 끝나는 파일의 내용이다. 확장자가 없는 쪽은 개인키이며 누구에게도 보여주면 안 된다 — 콘솔에 붙여넣어도 거절한다.

4. 접속 설정 받기

랩 노드는 사무실에서 직접 보이지 않는다. 운영 서버를 거쳐야 한다. 매번 이렇게 칠 수는 없다:

ssh -J {{ jump_user }}@{{ jump_ip }} {{ lab_user }}@{{ example_ip }}   # {{ example_node }}

아래에서 내 설정을 받아 ~/.ssh/config 에 붙이면 ssh {{ example_node }} 한 줄로 끝난다.

내 SSH 설정 내려받기 ssh-config-lab{{ lab_id }} 

cat ssh-config-lab{{ lab_id }} >> ~/.ssh/config
chmod 600 ~/.ssh/config
ssh {{ example_node }}

이 설정은 배정된 랩({{ lab_label }}) 기준이다. 랩이 바뀌면 다시 받아야 한다.

5. 콘솔 — SSH 가 죽었을 때

자기가 관리 링크를 내리면 SSH 자체가 끊긴다. 그때 되돌릴 유일한 길이 화면에 직접 붙는 콘솔이다. 실무의 콘솔 케이블·터미널 서버와 같은 자리다.

콘솔은 키를 쓸 수 없다. 그래서 여기만 비밀번호로 들어간다.
