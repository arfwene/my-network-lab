1. 키 만들기

Windows — 시작 메뉴에서 PowerShell 을 검색해 엽니다. 설치할 것은 없습니다(Windows 10 이상에 SSH 가 기본 포함).

ssh-keygen -t ed25519 -C "{{ user.username }}@내PC"

세 번 묻습니다. 전부 그냥 Enter (저장 위치 기본값, 암호 없음). 그다음 아래로 공개키를 꺼냅니다.

Get-Content $HOME\.ssh\id_ed25519.pub

ssh-ed25519 AAAA... 로 시작하는 한 줄이 나옵니다. 그 줄을 통째로 복사해 아래에 붙여넣습니다.

같은 폴더에 이름이 비슷한 파일이 둘 있습니다.
id_ed25519.pub = 공개키 — 남에게 줘도 되는 자물쇠
id_ed25519 (.pub 없음) = 개인키 — 누구에게도 주지 않는 열쇠
둘을 바꿔 내는 것이 가장 흔한 사고입니다. 개인키를 붙여넣으면 이 화면이 거절합니다.

macOS · Linux 를 쓴다면 
ssh-keygen -t ed25519 -C "{{ user.username }}@내PC"
cat ~/.ssh/id_ed25519.pub

ssh 명령이 없다고 나오면 — Windows 설정 → 시스템 → 선택적 기능 → 기능 추가 → OpenSSH 클라이언트.

내 SSH 설정 내려받기 ssh-config-lab{{ lab_id }} · 터미널에서 ssh {{ example_node }}

Windows — 받은 파일은 보통 다운로드 폴더에 있습니다.

New-Item -ItemType Directory -Force $HOME\.ssh | Out-Null
Get-Content $HOME\Downloads\ssh-config-lab{{ lab_id }} | Add-Content $HOME\.ssh\config
ssh {{ example_node }}
macOS · Linux 를 쓴다면 
mkdir -p ~/.ssh
cat ~/Downloads/ssh-config-lab{{ lab_id }} >> ~/.ssh/config
chmod 600 ~/.ssh/config
ssh {{ example_node }}

Xshell 세션 내려받기 my-network-lab-lab{{ lab_id }}.zip · 세션 {{ node_count }}개

압축을 풀면 my-network-lab 폴더가 나옵니다. 그 폴더를 통째로 Xshell 의 세션 폴더에 넣으면 세션 목록에 그대로 나타납니다.

문서\NetSarang Computer\8\Xshell\Sessions\

Xshell 에는 ProxyJump 가 없습니다. 대신 프록시 종류 JUMPHOST 가 같은 일을 하는데, 프록시는 세션 파일이 아니라 Xshell 의 프록시 목록에 등록됩니다. 그래서 처음 한 번만 직접 만들어 주셔야 합니다 — 폴더 안 읽어보세요.txt 에 그 절차가 있습니다.

이 설정은 배정된 랩({{ lab_label }}) 기준입니다. 랩이 바뀌면 다시 받아야 합니다.

5. 콘솔 — SSH 가 죽었을 때

자기가 관리 링크를 내리면 SSH 자체가 끊깁니다. 그때 되돌릴 유일한 길이 화면에 직접 붙는 콘솔입니다. 실무의 콘솔 케이블·터미널 서버와 같은 자리입니다.

콘솔은 키를 쓸 수 없습니다. 그래서 여기만 비밀번호로 들어갑니다.

비밀번호를 두 번 넣습니다. 하나는 Proxmox 웹에 들어가는 것, 하나는 그 안에서 열린 노드 화면에 로그인하는 것입니다. 서로 다른 값입니다.

Proxmox 계정은 {{ lab_label }} 교육생이 함께 씁니다. 이 계정으로는 화면 보기만 됩니다 — VM 을 끄거나 지우거나 설정을 바꿀 수 없습니다. 그건 이 웹 콘솔의 버튼이 하는 일입니다.
